# 카드 비교 도구 · shakilabs

**▶ 라이브 서비스: <https://shakilabs.com/card>**

주유 할인카드, 해외결제 수수료, 마일리지 가치, 연회비 회수 등 카드 선택 계산기 모음.

## 주요 도구

- [주유 할인카드 비교](https://shakilabs.com/card/fuel-card)
- [해외결제 수수료](https://shakilabs.com/card/overseas-payment)
- [마일리지 가치](https://shakilabs.com/card/mileage)
- [연회비 회수](https://shakilabs.com/card/annual-fee)
- [해외직구 관세](https://shakilabs.com/card/customs)

전체 서비스 12종: <https://shakilabs.com>

## 스택

Vue 3 (Composition API) · TypeScript · Vite · Tailwind CSS · 공유 UI `@shakilabs/ui`
정적 프리렌더/SSG로 배포하며, 계산 로직은 Vitest 경계값 테스트로 검증합니다.

## 개발

```bash
cd client
npm install
npm run dev
```
